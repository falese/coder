# ADR-017 — Typed domain errors

Status: Accepted

## Decision

All domain failures raised inside `packages/core` MUST be thrown as typed
subclasses of `DomainError` (for example `CartEmptyError`, `PaymentDeclinedError`).
A bare `throw new Error("…")` in domain code is forbidden: callers branch on the
error's constructor to decide recovery, and a plain `Error` collapses every failure
into one indistinguishable type. A lint exemption may be granted inline with an
`adr-lint-ignore` comment where a third-party boundary makes a typed error
impossible.
