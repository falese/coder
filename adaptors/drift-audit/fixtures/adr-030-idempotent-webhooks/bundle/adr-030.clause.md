# ADR-030 — Idempotent webhook handlers

Status: Accepted

## Decision

Every webhook handler MUST dedupe on the provider's event id BEFORE performing any
side effect (ledger write, email, downstream call). Providers retry deliveries, so a
handler that acts before checking whether the event id was already processed will
double-apply on retry. The dedupe check is the first statement in the handler; side
effects come after.
